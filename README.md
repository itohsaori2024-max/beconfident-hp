# 株式会社Be Confident ホームページ

営業スキルアップ・コンサルティング「株式会社Be Confident」のトップページ案（デモ）です。

## これは何か

`index.html` は、ブラウザで開くだけで見られる**トップページの完成イメージ（1枚もの）**です。
**白基調・ウォームエレガント版**（白 × チャコール × ローズ）で、明朝体の大見出しと、代表写真をババーンと配置するヒーローが特徴です。

- ヒーロー右側は**写真の差し込み枠**です。白背景で切り抜いた笑顔の写真を入れてください。
- キャッチコピーは「**売ることがみなさまを幸せにする**」。受講者の声・代表名・数値は**仮テキスト**です。
- 会社概要は提案資料の**実データ**（銀座の所在地・事業内容・資本金・設立日など）を反映しています。

## 見方

`index.html` をダブルクリックしてブラウザで開くだけです。ネットワーク接続やビルドは不要です。

## SWELL への落とし込み方（概要）

このHTMLは「設計図」です。SWELL本体では、次のように再現していきます。

1. **カラー設定**：`外観 > カスタマイズ > 色` で、キーカラーにローズ `#E0899F`、背景をネイビー系に設定。
2. **フルワイド＋カバーブロック**：各セクションは SWELL の「フルワイド」ブロックや「カバー」ブロックで背景色を敷いて再現できます。
3. **追加CSS**：細かい見た目（グラデーション、ホバー、区切り線など）は `外観 > カスタマイズ > 追加CSS` に、このファイルの `<style>` から必要な部分をコピーして調整します。
4. **セクション見出し**：縦バー＋英字ラベル付きの見出しは、SWELL の見出しブロック＋追加CSSクラスで再現します。

> まずはこのデモを見て「この方向でOK / ここを変えたい」を決め、そのうえで SWELL に一つずつ移していくのがおすすめです。
